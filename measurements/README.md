# Проверка первого включения

Результатов измерений на реальных платах пока нет. Программные проверки описаны
в [tests](../tests/README.md). Ниже — последовательность проверки ADC Web на столе.

1. Сверить разводку с [картой GPIO](../firmware/PINOUT.md), проверить питание и GND.
2. Проверить SWD и запуск MCU без подключённого TRX.
3. Проверить напряжение питания W5500, RESET и уровни CS.
4. Прочитать идентификатор версии W5500, проверить Ethernet link.
5. Открыть http://172.16.236.220:5025/ с компьютера в нужной подсети.
   Проверить показания PA0/PA1 при подключении к GND, к 3.3 В и к движкам
   двух потенциометров. Убедиться в обновлении кодов и времени работы.
6. Проверить отключение кабеля, повторное подключение и неполный запрос.
7. Подключить LCD/74HC595 и проверить отсутствие изменений выходов 595
   при Ethernet-трафике без импульса LATCH.
8. Проверить полную запись цепочки 595 с последующим защёлкиванием.

Для отчёта фиксировать дату, ревизии плат, версию прошивки, схему питания,
частоту SPI, средства измерения и фактический результат.

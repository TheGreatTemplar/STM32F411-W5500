# Сценарии

- `build.ps1` — сборка C99/ArmClang 6.19, ARMASM, линковка и выпуск AXF/HEX/BIN.
- `embed_web.py` — преобразование HTML в массив UTF-8 для хранения во Flash.
- `test.ps1` — сборка прошивки и макетов, запуск ARM-кода проверок через Unicorn.

Параметр `-Toolchain` позволяет задать другую установку Keil.
Для `test.ps1` параметр `-Python` задаёт Python с тестовыми зависимостями.
Лицензионные ключи не передаются через сценарии и не хранятся в репозитории.

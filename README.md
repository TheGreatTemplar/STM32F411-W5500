# STM32F411 + W5500

**Ethernet-контроллер для лабораторных стендов и радиоаппаратуры.**

Black Pill на STM32F411CEU6 и Ethernet-модуль W5500 станут основой локального
веб-интерфейса для управления устройствами: стендом контроля RFIC03,
трансивером [FLyEl-TRX](https://github.com/TheGreatTemplar/FlyEl-TRX) и другими модулями.

> **Сейчас:** подготовлены структура проекта и предварительная распиновка с учётом
> переноса TRX с STM32F103. Прошивка веб-сервера ещё не реализована;
> электрические соединения на стенде не проверены.

## Платформа

| Компонент | Выбор |
| --- | --- |
| MCU | STM32F411CEU6, Black Pill |
| Ethernet | W5500, интерфейс SPI |
| Среда | Keil µVision 5.38 |
| Компилятор | Arm Compiler 6.19 / ArmClang |
| Язык | C99; ассемблер при необходимости |
| Доступ к периферии | CMSIS и регистры MCU |
| Загрузка и отладка | SWD, ST-Link |
| Стиль C | Allman, 4 пробела, без табуляции |

Arduino, Wiring, STM32 HAL и PlatformIO в проекте не используются.

## Подключение W5500

| W5500 | STM32F411 | Примечание |
| --- | --- | --- |
| SCK | PA5 | Общая SPI1 с LCD и 74HC595 |
| MISO | PA6 | Выделен из резерва исходного TRX |
| MOSI | PA7 | Общая SPI1 |
| CS / SCSn | PA15 | Отдельный выбор Ethernet |
| RSTn | PB2 | GPIO после старта; учитывать BOOT1 при загрузке |
| INTn | Не подключён | Опрос в первой реализации |
| GND | GND | Общая земля |
| VCC | По схеме модуля | Проверить регулятор и допустимое питание модуля |

LCD_RST переносится **PB11 → PA12**: у STM32F411CEU6 нет PB11.
PA2 сохраняется как аналоговый резерв. Полная карта, конфликты кнопки KEY,
дополнительной Flash и USB, а также правила общей SPI описаны в
[PINOUT.md](firmware/PINOUT.md).

PC14/PC15 выделены под кварц LSE 32.768 кГц. При штатной загрузке из Flash
BOOT0 должен быть LOW; для ROM-загрузчика также требуется LOW на PB2/BOOT1.

## Структура репозитория

Организация согласована с FLyEl-TRX.

| Каталог | Содержимое |
| --- | --- |
| `src/` | Будущие исходники C99/CMSIS |
| `firmware/` | Распиновка, сборка и отладка |
| `hardware/` | Схемы, платы, подключения и BOM |
| `documentation/` | Архитектура, протоколы и описание работы |
| `scripts/` | Будущие сценарии сборки и проверок |
| `tests/` | Будущие проверки логики и протоколов |
| `measurements/` | Измерения и результаты испытаний |
| `mechanical/` | Корпус, крепления и 3D-модели |
| `tooling/` | Оснастка и вспомогательные приспособления |

Каталоги пока содержат описания назначения. Проект `.uvprojx` и готовые
бинарные файлы будут добавлены вместе с первой реализацией прошивки.

## Ближайшие этапы

1. Сверить ревизию Black Pill, модуль W5500 и цепи питания.
2. Подготовить запуск MCU, GPIO, таймер времени и SPI на CMSIS.
3. Проверить W5500: сброс, регистры, Ethernet link и TCP-сокет.
4. Реализовать небольшой HTTP-сервер и страницу состояния.
5. Добавить командный интерфейс и драйверы устройств по согласованным протоколам.
6. Проверить совместную работу Ethernet, дисплея и цепочки 74HC595.

Назначения интерфейсов RFIC03 будут определены после получения схемы и протокола.
TX_ACTIVE на PA8 остаётся **входом статуса**, а не командой включения передатчика.

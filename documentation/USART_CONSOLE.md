# Тест USART1, версия 0.4.0

Асинхронный UART, без тактового вывода CK и RTS/CTS. Кнопка I2S — отдельный
неактивный резерв интерфейса; она не запускает I2C или USART.

| Сигнал | Black Pill | Режим |
| --- | --- | --- |
| TX | PA9 | USART1_TX AF7, push-pull, pull-up |
| RX | PA10 | USART1_RX AF7, pull-up |
| Земля | GND | Общая земля |

Подключи TX стенда к RX устройства и RX стенда к TX устройства. Для loopback
соедини PA9 с PA10. Уровни 3,3 В; RS-232 требует преобразователя уровней.
PA9 также может использоваться USB VBUS: текущая прошивка USB не включает.

## Форматы и работа

Скорости: 300, 600, 1200, 2400, 4800, 9600, 19200, 38400, 57600,
115200, 230400, 460800, 500000, 921600, 1000000 бод.
APB2 постоянно 12 МГц. До 500000 используется OVER16, для 921600 и 1000000 — OVER8.
115200 → BRR=104 → 115384 бод; 921600 → 923076 бод; 1000000 — точно по делителю.
`actual_baud` — расчёт, физическая точность зависит от кварца HSE.
USART автоматически запускается при старте стенда: 115200/8N1.

Данные 8 бит с None/Odd/Even; 7 бит с Odd/Even. STM32F411 не поддерживает
здесь 7N1/7N2. Стоп-биты 1/2. Для 7-битного режима TX с байтами >127 отклоняется,
RX маскируется до 7 бит. HEX строго проверяется, ASCII — коды 1…127.
Посылка 1…256 байт плюс выбранные 0…2 байта CR/LF/CRLF.
Четыре независимых поля/кнопки TX, один журнал RX. Общие HEX/ASCII и окончание строки.
Каждый счётчик включает добавленное окончание. Все четыре кнопки и параметры
блокируются на время TX; автоматической очереди/повтора USART нет.
Сообщения сохраняются при смене шин в RAM страницы, не после её перезагрузки.
«Очистить журнал» у заголовка RX очищает только локальный текст.

Изменение скорости, числа битов, чётности или стоп-битов сразу применяет
настройки. Отдельных кнопок включения/выключения нет.
Во время TX и применения параметров поля временно заблокированы. Смена формата — явная
граница приёма, байты на проводе во время переключения могут быть потеряны.
Настройки и RX-история сохраняются в ОЗУ до перезагрузки. Flash не используется.
Настройки периферии общие для всех клиентов. Передача/перенастройка/отключение
при незавершённом TX возвращают busy, не ставятся в скрытую очередь и не повторяются.
202 означает «принято», счётчик TX увеличивается только после USART TC, включая
последний стоп-бит. Потерянный HTTP-ответ не вызывает автоматическую повторную TX.

## DMA, приём, ограничения

RX: DMA2 Stream2 channel4, circular 2048 байт, HT/TC IRQ. USART1 IRQ обслуживает
IDLE/PE/FE/NE/ORE. Главный цикл дополнительно извлекает принятые байты. IRQ USART
и DMA имеют одинаковый приоритет 4; доступ главного цикла защищён PRIMASK.
DMA не останавливается при HTTP-чтении. Драйверная RX-история — 8192 байта.
TX: DMA2 Stream7 channel4, отдельный статический буфер 258 байт; без обращений
CPU к DR на каждом байте. Главный цикл отслеживает TC и время завершения,
но не задаёт интервалы между байтами. Контрольные интервалы в мс не ограничивают
скорость передачи или разрешение DMA.

Ошибка DMA останавливает USART и сбрасывает DMA2; этот контроллер сейчас выделен
только USART. DMA1 SPI2 не затрагивается. Ошибка TX по времени также останавливает
периферию; повторный запуск — изменением параметра USART. Счётчик DMA включает аварийные
сбросы, в том числе после тайм-аута. PE/FE/NE/ORE означают, что журнал мог содержать
ошибочные байты; наличие RX само по себе не подтверждает корректность устройства.

Каждый браузер читает RX своим курсором, не потребляя историю других клиентов.
GET выдаёт максимум 1024 байта HEX. Опрос 100 мс, при отставании — 10 мс.
`lost` — байты истории, перезаписанные до чтения данным клиентом; интерфейс суммирует
их. Локальный журнал ограничен 8192 **символами**, отдельно от 8192 **байт** MCU.
Очистка журнала не очищает счётчики периферии или данные других клиентов.

Без RTS/CTS нет гарантии сохранения произвольного непрерывного потока на максимальной
скорости: SPI1/W5500 работает на 3 МГц, HTTP/HEX добавляют накладные расходы.
Для первого теста используй 115200. Более высокие скорости удобны для коротких
посылок и проверки осциллографом; следи за lost и ORE. RX IRQ должны обслуживаться
быстрее половины DMA-буфера: на 1 Мбод 8N1 это 10,24 мс. Длительное запрещение
прерываний может потерять полный оборот DMA, который уже нельзя восстановить.

## Совместная работа с SPI

Тактирование постоянно: SPI2 не изменяет APB2 и BRR USART.
USART можно оставить включённым при передаче SPI. DMA1 обслуживает SPI2,
DMA2 — USART1. HTTP-команды SPI/I2C исполняются последовательно;
USART RX/TX обслуживаются аппаратно и через IRQ параллельно.
Это не планировщик одновременных стартов интерфейсов. [Частоты](CLOCKS.md).

## API

Все управляющие запросы — `POST /api/usart`, `X-Device-Control: 1`, точный
Content-Length и text/plain. Автоматического повтора нет.

```text
start baud=115200 bits=8 parity=0 stop=1\n
stop\n
tx format=0 eol=3\n55 AA 00 FF
```

В примерах `\n` — реальный LF. parity: 0 None / 1 Odd / 2 Even;
format: 0 HEX / 1 ASCII; eol: 0 None / 1 CR / 2 LF / 3 CRLF.
Порядок полей фиксирован. Конфигурация требует завершающего LF без хвоста.
Ответ `{error:0}` с 202 либо error 1 invalid, 2 busy, 3 disabled, 4 DMA.

`GET /api/usart?from=0`: статус, параметры, RX/TX totals, массив ошибок
PE/FE/NE/ORE/DMA/timeout, поля rx (HEX), next, more и lost. Последующий запрос
использует from=next. Курсор uint32, арифметика по модулю; запрашивать историю
старше 2^31 байт нельзя. Будущий курсор после сброса возвращается к сохранённому
началу истории. Несколько GET с одним курсором возвращают одни и те же байты,
пока история не была перезаписана.

## Проверки

`tests/usart_arm.py` исполняет скомпилированный ARM-код: 45 режимов baud/кадра,
DMA mapping, TX busy и TC, independent cursors, оборачивание буферов и lost,
строгий ввод, parity/noise/overrun/DMA faults и SPI DMA при активных USART TX/RX.
Это программная модель регистров, а не подтверждение осциллограммы на плате.

[STM32F411 RM0383: USART и DMA mapping](https://www.st.com/resource/en/reference_manual/dm00119316-stm32f411xce-advanced-armbased-32bit-mcus-stmicroelectronics.pdf).

# Часы стенда: RTC STM32F411

Календарь работает в аппаратном RTC от кварца **LSE 32,768 кГц на PC14/PC15**.
Делители 127 и 255 дают секундный ход. Переключение HSI/PLL для SPI2 не меняет
источник RTC. Используются CMSIS и регистры, без HAL.

На странице показаны дата и время микроконтроллера, полученные вместе с ADC JSON.
Это не часы компьютера и не счётчик времени работы. При отсутствии связи
показания очищаются; ошибка ADC не мешает отображать исправный RTC.

- **Установить:** задать дату и время в отдельных полях. Поддержаны любые
  существующие даты 2000–2099 и время 00:00:00–23:59:59. Можно использовать
  условное время для испытаний. Пустые и невозможные даты отклоняются.
- **Синхронизировать с ПК:** взять местные дату и время компьютера, на котором
  открыт браузер. Значение снимается перед отправкой запроса. Это ручная
  синхронизация по HTTP, с сетевой задержкой; точность до долей секунды не гарантируется.

RTC хранит календарное время без часового пояса. Автоматического перевода
летнего/зимнего времени, NTP и автоматической синхронизации при открытии страницы
нет. Ручной ввод не заменяется последующими обновлениями показаний.

При первом запуске отображается **«Время не установлено»**. Прошивка не
подставляет время сборки или компьютера. Признак установленного времени хранится
в RTC BKP0R/BKP1R. Обычный сброс MCU сохраняет часы и этот признак.
Для хода при отключении VDD требуется резервное питание **VBAT** по схеме платы.
Без него после полного обесточивания часы потребуется установить заново.
W25Q64JV для хранения часов не используется.

Запуск LSE проверяется до 8 секунд, без блокировки сетевого цикла. Если кварц
не запускается, страница сообщает об ошибке, кнопки установки недоступны.
Автоматического перехода на неточный LSI нет. Если в резервном домене уже
выбран другой источник RTC, прошивка сообщает о конфликте и не сбрасывает
резервный домен автоматически. Аппаратный запуск и точность LSE проверяются на плате.

## HTTP API

`GET /api/rtc` возвращает состояние:

```json
{"ready":true,"set":true,"lse_ready":true,"error":0,"datetime":"2032-02-29T12:34:56"}
```

Тот же объект доступен как `rtc` в `GET /api/adc`. Пока время не установлено,
`set=false`, `datetime=""`. Ошибки: 1 — другой источник RTC, 2 — тайм-аут LSE,
3 — тайм-аут INIT, 4 — несовместимая сохранённая конфигурация,
5 — некорректный/несогласованный календарь.

`POST /api/rtc`: заголовок `X-Device-Control: 1`, точный `Content-Length: 19`,
тело `YYYY-MM-DDTHH:MM:SS`, без перевода строки и часового пояса.
Полное тело и дата проверяются до записи. Ответ 200 содержит состояние после
установки; 400 — неверное тело/дата, 503 — RTC недоступен.
Запрос выполняется один раз, повторная отправка TCP-ответа не меняет часы снова.
При потере ответа браузер не повторяет установку автоматически.

Последовательности настройки и чтения сверены по
[ST RM0383, раздел 17](https://www.st.com/resource/en/reference_manual/rm0383-stm32f411xce-advanced-armbased-32bit-mcus-stmicroelectronics.pdf).

Панель часов находится перед аналоговыми каналами. Калибровка хода отдельно
описана как [предлагаемое расширение](RTC_CALIBRATION.md); CALR в этой версии не меняется.

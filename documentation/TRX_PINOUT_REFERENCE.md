# STM32F411 Black Pill + W5500: перенос TRX_Fly

> Исторический документ. Текущая разводка автономного стенда находится в
> [firmware/PINOUT.md](../firmware/PINOUT.md). Эти назначения TRX не относятся к SPI2-консоли.

Предварительная разводка для Black Pill с STM32F411CEU6. Основа —
`TRX_Fly_STM32F103C8T6_pinout_final.xlsx`, версия раскладки 2026-10-10,
листы «Распиновка» и «По функциям». Исходная таблица не изменена.
Перед монтажом требуется сверить ревизию имеющейся Black Pill и модуль W5500.
Названия PA/PB/PC обозначают GPIO, а не порядковые номера контактов гребёнок.
Black Pill не предполагается устанавливать в разъём Blue Pill без проверки разводки.

## W5500

| Сигнал модуля | Black Pill | Назначение |
| --- | --- | --- |
| SCK | PA5 | SPI1 SCK, общий с LCD и 74HC595 |
| MISO | PA6 | SPI1 MISO, в исходной таблице свободен |
| MOSI | PA7 | SPI1 MOSI, общий с LCD и 74HC595 |
| CS / SCSn | PA15 | Отдельный выбор W5500, active-low |
| RST / RSTn | PB2 | Отдельный сброс W5500, active-low; учитывать BOOT1 при загрузке |
| INT / INTn | Не подключать | Начальный сервер опрашивает контроллер |
| GND | GND | Общая земля |
| VCC | По схеме конкретного модуля | Сам W5500 питается от 3.3 В; наличие входа 5 В зависит от модуля |

Предусмотреть определённый высокий уровень CS при сбросе MCU (например, внешнюю
подтяжку к 3.3 В). Цепь RSTn проверить по схеме модуля: она может уже содержать
подтяжку и RC-цепь. PC14/PC15 зарезервированы для кварца LSE 32.768 кГц;
к W5500 их не подключать. Не рассчитывать на питание Ethernet
от регулятора Black Pill без проверки его допустимого тока и нагрева.

PB2 после запуска настраивается как GPIO-выход сброса W5500. При штатной загрузке
из Flash держать BOOT0=0: значение PB2/BOOT1 тогда не влияет на выбор загрузки.
Для входа в системный ROM-загрузчик при BOOT0=1 требуется PB2/BOOT1=0
в момент сброса MCU. Подтяжка RSTn на модуле W5500 может задавать здесь HIGH,
поэтому эту цепь нужно учитывать при использовании BOOT-загрузки. Перед принудительным
заданием LOW убедиться, что PB2 не управляется прошивкой как выход HIGH.
Основной способ загрузки проекта — SWD. После инициализации GPIO сформировать
импульс сброса W5500 с длительностью по его документации.

расположению I2C1. Для минимального переноса сохранить программную шину EEPROM.

## Условия работы общей SPI

1. Перед инициализацией SPI установить LCD_CS и W5500_CS в HIGH, 595_LATCH в LOW.
2. Выбирать только одно устройство с CS. Настройки режима и частоты задавать
   перед каждой транзакцией. Не обращаться к SPI из прерываний параллельно с сервером.
3. У 74HC595 нет CS. Все такты W5500/LCD сдвигают его внутренний регистр.
   Выходной регистр остаётся прежним, пока нет фронта LATCH.
4. Перед каждым фронтом LATCH передавать **всю** цепочку 74HC595 из теневого
   буфера без промежуточных транзакций других устройств.
5. Начать проверку с SCK не выше 1 МГц. При интеграции драйвера Ethernet проверить
   его собственные настройки SPI: одного вызова настройки SPI в main недостаточно.
   Повышать частоту после проверки дисплея, всей цепочки 595 и проводников.
6. Начальное состояние выходов 595 определяется отдельной схемой OE/MR и загрузкой
   безопасного слова. Удержание LATCH в LOW само по себе не задаёт состояние при питании.

## Особенности платы

- PA11/PA12 используются трансивером. USB CDC и USB DFU с подключённой периферией
  в этой разводке не предусмотрены. Загружать через ST-Link/SWD; USB допускается
  для питания кабелем без линий данных.
- На PA0 присутствует кнопка KEY. Для постоянного S-meter предусмотреть её
  отключение или учитывать влияние при нажатии. Уточнить схему ревизии платы.
- Если на Black Pill установлена дополнительная SPI Flash, её CS на PA4
  конфликтует с KEY_INT. Одна лишь неинициализация Flash конфликт не устраняет.
  В данной разводке Flash должна отсутствовать либо быть аппаратно отключена.
- ADC и внешние цифровые интерфейсы согласовать с уровнями 3.3 В. Условия
  подключения существующей клавиатуры/регистров зависят от их реального питания.
- RFIC03 пока не имеет назначенных сигналов: нужна его схема подключения/протокол.
  Нельзя занимать зарезервированные линии TRX произвольными выходами веб-сервера.

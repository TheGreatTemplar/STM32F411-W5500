# Калибровка RTC / LSE

Реализована аппаратная smooth calibration RTC_CALR с 32-секундным окном.
Кнопка «Калибровка» над «Установить» открывает отдельное окно. Ввод ppm,
«Рассчитать по уходу», «Сохранить и применить», «Сбросить поправку» действуют
явно. Никакой сетевой синхронизации или перестановки календаря при калибровке нет.
Кнопка сетевой синхронизации оставлена отключённой для следующего расширения.

## Формула и знак

Шаги s = CALP*512 − CALM, −511…+512. Частотный множитель RTC равен
1048576/(1048576−s); ppm = s*1000000/(1048576−s). Шаг около 0,954 ppm,
диапазон −487,09…+488,52 ppm. Положительная поправка ускоряет часы,
отрицательная замедляет. Ввод округляется к ближайшему аппаратному шагу,
а окно показывает фактическую квантованную поправку.

Для расчёта измерить e0 = RTC − эталон и e1 через T секунд без изменения
времени и поправки. Измеренный множитель ухода r = 1+(e1−e0)/T.
Новый множитель = старый калибровочный множитель / r. Затем вычисляется
ближайший допустимый шаг. Если RTC спешит на 3 секунды за 24 ч при нулевой
поправке, результат примерно −34,33 ppm (−36 шагов после квантования).
Для сравнения по целым секундам нужны 3–7 суток и стабильный эталон.
Сетевая задержка/квантование ограничивают измерение; это не автоматическая
калибровка по браузерным часам. Температура может менять уход кварца.

## Сохранение и применение

Поправка находится в отдельной системной записи W25Q64JV вместе с сетью,
с CRC и двумя копиями; см. NETWORK_SETTINGS.md. Сначала durable commit,
затем главный цикл запрашивает применение к RTC. Ожидание RECALPF=0
неблокирующее, с отдельным пределом 35 секунд после готовности LSE/RTC.
При ошибке сохранённая поправка остаётся во Flash, а окно сообщает отсутствие
подтверждения применения. Можно повторить явное применение; при следующей
загрузке валидная сохранённая поправка восстанавливается.

CALR пишется под WPR после проверки готовности; CALW8/CALW16 сброшены,
CALP/CALM проверяются чтением. PRER 127/255, TR/DR и BKP0/BKP1 не меняются.
Изменение действует по аппаратному калибровочному окну; чтение CALR подтверждает
принятую настройку, а не завершение измерения точности кварца. Ошибки:
1 диапазон, 2 RECALPF timeout, 3 RTC/LSE не готов, 4 readback CALR.
Системный GET возвращает их отдельно от ошибок Flash.

Для точной проверки использовать RTC calibration output 1/512 Гц с частотомером
и более точной опорой (например GPSDO). Этот вывод в прошивке не включён,
чтобы не занять GPIO/LED без выбора распиновки.

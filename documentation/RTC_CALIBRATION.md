# Предлагаемая калибровка RTC / LSE

Статус: **порядок следующего расширения**. В этой прошивке калибровочная
поправка ещё не задаётся. Ручная установка даты и синхронизация с ПК остались
отдельными явными операциями; произвольное время стенда не исправляется автоматически.

## Корректировать ход, а не переставлять время

Для STM32F411 подходит аппаратная smooth calibration через `RTC_CALR`,
с окном 32 секунды. Делители RTC оставить 127/255: нынешняя прошивка проверяет
их при старте. `CALM` замедляет календарь, сочетание `CALP`/`CALM` позволяет
ускорять его. Шаг около 0,954 ppm, диапазон примерно −487…+489 ppm.
[Источник: ST RM0383, раздел 17.3.11](https://www.st.com/resource/en/reference_manual/rm0383-stm32f411xce-advanced-armbased-32bit-mcus-stmicroelectronics.pdf).

Возможный интерфейс: «Поправка, ppm», «Рассчитать по уходу», «Применить»,
«Сбросить поправку». Применение только по кнопке, с ожиданием RECALPF=0
и ограниченным тайм-аутом. CALR меняется без сброса календаря. Поправку
хранить в отдельной системной записи с CRC/двумя копиями, вне банков преднастроек.
Резервные регистры BKP0/BKP1 уже заняты признаком установки RTC.

## Практический замер по компьютеру

1. Дать плате прогреться в обычных условиях. Использовать стабильный эталон времени.
2. Записать исходное расхождение `e0 = RTC − эталон`, затем конечное `e1`.
   Между замерами не менять RTC, не синхронизировать и не менять поправку.
   Для стенда с условной датой важно изменение расхождения, а не сама дата.
3. За интервал `T` секунд уход равен `(e1 − e0) × 1000000 / T` ppm.
   Нужная поправка имеет противоположный знак: RTC спешат → замедлить.
4. По возможности измерять 3–7 суток. API сейчас отдаёт целые секунды;
   квантование, сетевые задержки и нестабильность эталона ограничивают точность.
   За сутки одна секунда ошибки соответствует 11,574 ppm. Несколько суток
   дают практическую грубую поправку, но не гарантируют точность в один шаг CALR.

Пример: если **изменение** расхождения за 86400 секунд равно +3 секундам,
RTC спешат примерно на 34,72 ppm; целевая поправка около −34,72 ppm.
Округление CALR и повторный замер определят результат, а не один снимок браузера.
При смене температуры уход может измениться; одной константой это полностью
не компенсируется.

## Точный замер прибором

Для тонкой настройки использовать калибровочный выход RTC 512 Гц или 1 Гц
и частотомер/счётчик интервалов с эталоном лучше желаемой точности, например
GPSDO. Обычный осциллограф без точной опоры не обязательно точнее кварца RTC.
Вывод калибровки потребует отдельного режима и проверки конфликта с GPIO/LED.
Он в этой версии не включается.

Измерять несколько полных 32-секундных окон и использовать фронты,
указанные документацией RTC. Повторить после применения поправки и при
рабочей температуре. Для субсекундного сравнения с ПК потребуется расширить
API: согласованное чтение SSR/TR/DR и оценка задержки запроса; это также
отдельная задача.

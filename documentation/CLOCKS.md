# Постоянное тактирование — версия 0.3.0

Плата: Black Pill STM32F411CEU6, подтверждённый пользователем кварц HSE SJK 25 МГц.
Марка кварца не задаёт его допуск: приведённые скорости расчётные, без учёта ppm.

## Дерево частот

HSE / PLLM25 × PLLN192 / PLLP2 = 96 МГц. VCO 192 МГц, PLLQ4 = 48 МГц.
48 МГц подготовлены для будущего USB; USB сейчас не включён.

| Узел | Частота / настройка |
| --- | --- |
| SYSCLK / AHB / Cortex-M4 | 96 МГц |
| APB1 | 48 МГц, AHB /2 |
| APB2 | 12 МГц, AHB /8 |
| Таймеры APB1 / APB2 | 96 / 24 МГц, TIMPRE=0 |
| DWT | 96 тактов/мкс |
| SysTick | 1 мс, LOAD=95999; служебный учёт времени |
| ADC1 | APB2 /2 = 6 МГц, выборка 480 тактов |
| SPI1 W5500 + W25Q64JV | APB2 /4 = 3 МГц, mode 0 |
| RTC | Независимый LSE 32768 Гц, PC14/PC15 |

APB2 выбран 12 МГц, чтобы USART1 поддерживал одновременно низкие 300 бод
и верхний 1 Мбод. На точные интервалы SPI SysTick не влияет: обмен через DMA,
дедлайны и измерение длительности через DWT. PLL при командах не переключается.

## SPI2

| BR / делитель APB1 | SCK |
| --- | --- |
| 7 /256 | 187500 Гц |
| 6 /128 | 375000 Гц |
| 5 /64 | 750000 Гц |
| 4 /32 | 1500000 Гц |
| 3 /16 | 3000000 Гц |
| 2 /8 | 6000000 Гц |
| 1 /4 | 12000000 Гц |
| 0 /2 | 24000000 Гц |

**Минимум аппаратной SPI2 при этом плане — 187,5 кГц, максимум — 24 МГц.**
Промежуточные старые 1/2/4/10/20/25 МГц недоступны без смены общего тактирования.
Старые наборы Flash читаются с исходными значениями. Для недоступной частоты
показывается предупреждение и передача заблокирована до явного выбора новой.
Чтение набора само по себе не переписывает Flash; формат v5 и адреса банков сохранены.

## I2C1

CR2.FREQ=48. Standard: CCR=240, TRISE=49 → 100 кГц.
Fast, duty=2: CCR=40, TRISE=15 → 400 кГц. Реальные фронты определяются подтяжками
и ёмкостью проводов. Адрес, ACK/NACK, repeated START и тайм-ауты сохранены.

## USART1

BRR округляется от 12 МГц. 300…500000 бод используют OVER16,
921600/1000000 — OVER8. Скорости 300, 600, 1200, 2400, 4800, 9600,
19200, 38400, 57600, 115200, 230400, 460800, 500000, 921600, 1000000.

| Выбрано, бод | Расчётно, бод | Отклонение округления |
| --- | --- | --- |
| 115200 | 115384,615 | +0,1603% |
| 230400 | 230769,231 | +0,1603% |
| 460800 | 461538,462 | +0,1603% |
| 500000 | 500000 | 0% |
| 921600 | 923076,923 | +0,1603% |
| 1000000 | 1000000 | 0% |

Страница показывает расчётную скорость и ошибку делителя. Это не частотомер.
USART можно оставить включённым при передаче SPI. DMA1 обслуживает SPI2,
DMA2 — USART1. HTTP-команды SPI/I2C исполняются последовательно;
непрерывные USART RX/TX работают аппаратно и через IRQ в фоне.
Гарантированных одновременных стартов нескольких интерфейсов пока нет.
I2S ещё не реализован: PLLI2S, выводы и конфликты с SPI нужно выбрать отдельно.

## Запуск и отказ кварца

При запуске проверяются HSI, HSE, PLL, VOSRDY, Flash latency и переключение SYSCLK.
Ожидания ограничены по DWT и числу попыток. На отказе периферия не запускается,
синий LED горит постоянно. Через SWD доступна переменная `clock_error`:
1 — HSI/переход HSI, 2 — остановка PLL/HSE, 3 — HSE,
4 — питание/Flash, 5 — PLL, 6 — переход на PLL/контроль частоты.
CSS при пропадании HSE останавливает интерфейсы и вызывает системный reset.
Это предотвращает дальнейшую передачу с неверными делителями, но не отменяет
уже переданные биты. После reset HSE проверяется заново.

## Проверки

ARM/Unicorn: штатный и повторный запуск, отказы HSI/HSE/PLL/VOS/переключения,
CSS/NMI/reset, делители всех интерфейсов, SPI DMA при активных USART TX/RX,
HTTP, сохранённые наборы и RTC. Это модели регистров, не эмуляция аналогового
кварца или точная модель арбитража шин. Нужна проверка новой сборки на плате.

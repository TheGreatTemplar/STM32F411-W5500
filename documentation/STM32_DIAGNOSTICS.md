# Диагностика STM32 и информация о сборке

Кнопка «Диагностика STM32F411» открывает АЦП, счётчик измерений, опорное
напряжение, LED и статистику внешней Flash. Кнопка «Обновить» запрашивает
`GET /api/mcu`. Это снимок каталога в ОЗУ: дополнительных чтений или записей
W25Q64JV для него не выполняется. После сохранения или удаления набора обнови
снимок. Пока каталог сканируется или переносится, числа слотов скрыты. При записи
показывается последний подтверждённый каталог с соответствующим сообщением.

## Разметка W25Q64JV

| Назначение | Адреса включительно | Размер |
| --- | --- | --- |
| Пока не выделено под функции | `0x000000–0x6EDFFF` | 7 266 304 байта / 6,9296875 МиБ |
| Справка, две копии по 32 КиБ | `0x6EE000–0x6FDFFF` | 65 536 байт |
| IP, маска, шлюз, порт, поправка RTC | `0x6FE000–0x6FFFFF` | 8192 байта |
| I2C: 64 набора | `0x700000–0x77FFFF` | 524 288 байт |
| SPI: 64 набора | `0x780000–0x7FFFFF` | 524 288 байт |

В каждой банковской строке показаны живые наборы, доступные для повторного
использования слоты и недоступные слоты с повреждёнными/чужими данными. Один
слот резервирует 8192 байта — две копии по сектору. Даже короткий набор занимает
один слот. Удалённый набор входит в свободные слоты; недоступные слоты туда не
входят. Сумма трёх счётчиков каждой шины равна 64.

Число байтов рядом со счётчиком — резерв соответствующих слотов, а не число
физически запрограммированных байтов. Формат записи v5 занимает 4068 байт на
копию. Неразмеченные 7 266 304 байта не сканируются: наличие там стёртых байтов
или сторонних данных этим API не проверяется. USART и I2S пока не имеют банков.
Новая диагностика не меняет формат, адреса или содержимое сохранённых настроек.

## «О программе»

Из окна STM32 открывается отдельное окно с версией ПО, датой сборки UTC,
базовым коммитом, SHA-256 исходников, CRC32 веб-страницы, компилятором и C99/CMSIS.
Первая явно нумерованная версия — `0.1.0`; версия и базовая ревизия задаются в
`firmware/version.json`.

`scripts/build_info.ps1` запускается перед сборкой CLI и как BeforeMake в Keil.
Он создаёт `src/build_info.h`; при обычной сборке Keil не нужны Python и сеть.
Скрипт не изменяет пользовательские настройки среды. Дата обновляется при каждой
сборке; SHA-256 не зависит от даты и пути checkout.

SHA-256 вычисляется для UTF-8 манифеста строк `относительный/путь:sha256_файла\n`,
отсортированных по полному имени файла с `StringComparer.Ordinal` (независимо
от языка Windows и версии PowerShell). Включены файлы `src`, `third_party`,
`firmware`, `scripts` и проект `adc_web_f411.uvprojx`; исключены генерируемые
`build_info.h`, `web_page.h` и `.pyc`. Веб-страница участвует исходным HTML.
CRC32 — CRC-32/ISO-HDLC исходных байтов `src/web/index.html`, без завершающего NUL.
Начиная с 0.2.2 HTTP передаёт gzip. Значение CRC32 в About по-прежнему относится
к распакованному HTML; оно совпадает с CRC32 в трейлере gzip. Сжатый поток
не распаковывается микроконтроллером и не копируется целиком в ОЗУ.

Базовый коммит — предшествующая ревизия, от которой сделаны изменения; SHA-256
идентифицирует фактическое состояние исходников. Коммит, содержащий собственный
идентификатор в коде, получить нельзя без изменения этого идентификатора.
CRC32 страницы не является CRC32 всего BIN/HEX и не служит проверкой внутренней
Flash микроконтроллера. Для проверки загруженного HEX используй Verify в Keil.

API `GET /api/mcu` возвращает объекты `firmware` и `storage`. Данные не включают
содержимое команд или пароли. Запрос не зависит от доступности регистров W5500
для диагностического чтения; штатное HTTP-соединение всё равно требуется.

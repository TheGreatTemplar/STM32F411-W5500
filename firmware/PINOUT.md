# Распиновка автономного стенда STM32F411 + W5500

Текущая прошивка предназначена для отдельного стенда Black Pill STM32F411CEU6.
Разводка TRX не применяется к SPI-консоли. Историческая карта сохранена в
[TRX_PINOUT_REFERENCE.md](../documentation/TRX_PINOUT_REFERENCE.md).
Названия PA/PB/PC — GPIO микроконтроллера, а не номера контактов гребёнок.

## Ethernet: SPI1 / W5500

| W5500 | Black Pill | Назначение |
| --- | --- | --- |
| SCK | PA5 | SPI1 SCK, режим 0, 1 МГц |
| MISO | PA6 | SPI1 MISO |
| MOSI | PA7 | SPI1 MOSI |
| CS / SCSn | PA15 | Active-low, HIGH между транзакциями |
| RSTn | PB2 | Active-low; учитывать BOOT1 |
| INTn | Не подключён | Опрос состояния в прошивке |
| GND | GND | Общая земля |
| VCC | По схеме модуля | Проверить вход питания конкретного модуля |

PB2 после запуска используется как выход сброса. При загрузке из Flash BOOT0=0.
Для входа в ROM-загрузчик при BOOT0=1 требуется PB2/BOOT1=0 во время сброса MCU.
Основной способ загрузки — SWD.

## Внешнее устройство: SPI2

| Сигнал | Black Pill | Назначение |
| --- | --- | --- |
| CS | PB12 | Программный CS; active-low по умолчанию, active-high по настройке команды |
| SCK | PB13 | SPI2 SCK, AF5 |
| MISO | PB14 | Данные от внешнего устройства |
| MOSI | PB15 | Данные к внешнему устройству |
| GND | GND | Общая земля с устройством |

SPI2 отделена от SPI1 Ethernet. Режим 0–3, частота, порядок битов и полярность
CS задаются для каждой команды. Формат кадра — 8 бит. До первой команды CS
на PB12 установлен HIGH: это начальное состояние рассчитано на active-low.
Для устройств с active-high CS учитывать этот уровень при подключении и сбросе.

Частоты: 62,5 / 125 / 250 / 500 кГц, 1 МГц и 2…20 МГц с шагом 2 МГц.
Для части частот на время передачи включается PLL от HSI; после обмена
возвращается HSI 16 МГц. Подробнее — [SPI_CONSOLE.md](../documentation/SPI_CONSOLE.md).

## Внешнее устройство: I2C1

| Сигнал | Black Pill | Назначение |
| --- | --- | --- |
| SCL | PB8 | I2C1 SCL, AF4, open-drain |
| SDA | PB9 | I2C1 SDA, AF4, open-drain |
| GND | GND | Общая земля |

Внешние подтяжки обеих линий **к 3,3 В** обязательны; для короткой линии
начать с 4,7 кОм и проверить фронты. Адрес 7-битный, частота 100 кГц или
Fast mode до 400 кГц (делитель при HSI 16 МГц даёт 380952 Гц).
Выводы независимы от SPI1/SPI2 и LSE. [I2C-консоль](../documentation/I2C_CONSOLE.md).

## Внешняя Flash: W25Q64JV, 8 Мбайт

| Сигнал | Black Pill | Назначение |
| --- | --- | --- |
| /CS | PA4 | Отдельный active-low выбор Flash |
| CLK | PA5 | Общий SPI1 SCK с W5500 |
| DO / MISO | PA6 | Общий SPI1 MISO |
| DI / MOSI | PA7 | Общий SPI1 MOSI |

SPI1 mode 0, 1 МГц. Перед обращением к Flash CS W5500 на PA15 снимается,
перед обращением к W5500 снимается CS Flash. Зарезервирован последний 1 Мбайт:
SPI 0x780000…0x7FFFFF и I2C 0x700000…0x77FFFF, по 64 набора; остальная ёмкость доступна для будущих задач.
Транзакция выполняется целиком, CS освобождается после последнего бита либо ошибки.
Линии — логика 3,3 В; входы/выходы внешнего устройства должны быть согласованы.
Не подключать PB12–PB15 одновременно к старым цепям LCD, энкодера или 74HC595.
Для теста без внешнего устройства можно соединить PB15 MOSI с PB14 MISO:
полученные RX-байты должны повторять TX.

## Измерения, индикация и системные выводы

| Назначение | GPIO |
| --- | --- |
| ADC1_IN0 | PA0, 0…VDDA; кнопка KEY платы влияет на этот вход |
| ADC1_IN1 | PA1, 0…VDDA |
| Аналоговый резерв | PA2, не занят |
| Синий LED | PC13, active-low |
| LSE / RTC | PC14 OSC32_IN / PC15 OSC32_OUT, кварц 32,768 кГц; GPIO не используются |
| SWD | PA13 SWDIO / PA14 SWCLK |
| Сброс MCU | NRST |

Выводы неиспользуемой периферии TRX в этой прошивке не назначаются.
Основная частота MCU — HSI 16 МГц; для некоторых частот SPI2 временно используется
PLL от HSI. Кварц HSE для работы теста не требуется.
Питание W5500 проверить отдельно по допустимому току регулятора и схеме модуля.

# Исходники

| Файл | Назначение |
| --- | --- |
| `startup_stm32f411.s` | Таблица векторов и вход в C runtime Arm |
| `board.c` | HSI 16 МГц, SysTick, GPIO, SPI1, два канала ADC1 |
| `w5500.c` | Регистры W5500, статическая сеть, TCP socket 0 |
| `http_parse.c` | Ограниченный разбор HTTP-запроса |
| `http.c` | Страница, JSON API, обслуживание соединения |
| `main.c` | Измерения, сеть и повторная инициализация |
| `config.h` | IP, порт, MAC, интервалы и опорное напряжение |
| `web/index.html` | Исходник страницы |
| `web_page.h` | Встроенные UTF-8 байты страницы, генерируются скриптом |

Используются C99, CMSIS и регистры MCU. Аппаратные IRQ, кроме SysTick, в тесте
не включаются; их векторы указывают на Default_Handler. При добавлении IRQ
потребуется заменить соответствующие векторы в startup.

Сетевые настройки

Статический IPv4. Шлюз 0.0.0.0 отключает маршрутизацию. Маска /1–/30. Сначала запись Flash, затем смена адреса через 2 секунды.

Калибровка RTC / LSE

Расхождение = RTC − эталон. Между замерами не менять время и поправку. Для сравнения по целым секундам измерять 3–7 суток.

Подтверждение сброса

Сбросить поправку RTC до 0 ppm? Нулевая поправка будет сохранена во Flash и применена к часам.

Неразмеченная область доступна для будущих функций. Проверка её содержимого не выполняется; это не счётчик стёртых байтов.

О программе

SHA-256 определяет исходники сборки. Базовый коммит — отправная точка изменений; он не выдаётся за коммит готовой прошивки. CRC32 относится к веб-странице, а не ко всему HEX.

Счётчики относятся к драйверу TCP-сокета; это не полный Ethernet-трафик, не число пакетов и не ошибки CRC. Значения 32-битные, при переполнении начинаются с нуля.
